Classement

    Ajouter ou retirer une map

    La liste est dans le fichier maps.json. Ajoute une ligne avec le code de l'île et son nom, puis valide. La map apparaît dans la minute.

    Modifier sur GitHub

    Notifications toutes les heures

    Chaque heure, MyUEFN t'envoie les joueurs connectés et le revenu de la dernière heure, map par map.

    Dernière étape : donne ce code à GitHub.

    Ouvrir GitHub
    1. Dans GitHub, écris MYUEFN_PUSH dans « Name ».
    2. Colle le code dans « Secret », puis appuie sur « Add secret ».
    3. La notification suivante arrive au prochain relevé.

      Rien pour l'instant. Les premières lignes arrivent au prochain relevé horaire.
